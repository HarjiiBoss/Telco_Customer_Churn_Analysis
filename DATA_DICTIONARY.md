# Data Dictionary

This document describes the primary datasets, tables, and key analytical fields used throughout the **Telco Customer Churn Analysis** project.

The SQL outputs serve as the single source of truth. Excel references these outputs directly without recalculating core business metrics.

---

# Customer Analysis

## tbl_ChurnByContract

| Column | Description |
|----------|-------------|
| Contract | Customer contract type (Month-to-month, One year, Two year) |
| Total Customers | Number of customers within each contract type |
| Churned | Number of customers who left the company |
| Churn Rate (%) | Percentage of customers who churned within each contract type |

---

## tbl_ChurnByTenureBand

| Column | Description |
|----------|-------------|
| Tenure Band | Customer tenure grouped into lifecycle segments |
| Total Customers | Number of customers in each tenure band |
| Churned | Number of churned customers |
| Churn Rate (%) | Percentage of customers who churned within the tenure band |

---

## tbl_ChurnByInternetService

| Column | Description |
|----------|-------------|
| Internet Service | Customer internet service type |
| Total Customers | Number of customers using the service |
| Churned | Number of churned customers |
| Churn Rate (%) | Percentage of customers who churned |

---

## tbl_ChurnByPaymentMethod

| Column | Description |
|----------|-------------|

| Total Customers | Number of customers using the payment method |
| Churned | Number of churned customers |

## tbl_AvgTenureByChurn

# Risk Analysis

## tbl_ConcentrationRisk

| Column | Description |
|----------|-------------|
| Contract | Customer contract type |
| Total Customers | Number of customers |
| Customer Share (%) | Percentage of total customer base |
| Monthly Revenue (£) | Monthly revenue contributed |
| Revenue Share (%) | Percentage contribution to total revenue |

---

## tbl_InternetServiceConcentration

| Column | Description |
|----------|-------------|
| Internet Service | Internet service category |
| Customer Share (%) | Share of customers |
| Monthly Revenue (£) | Monthly revenue contribution |
| Revenue Share (%) | Share of total monthly revenue |
| Churn Rate (%) | Percentage of customers who churned |

---

## tbl_HighRiskCustomers

| Column | Description |
|----------|-------------|
| Risk Segment | High Risk or Standard customer profile |
| Total Customers | Number of customers within the risk profile |
| Churned | Number of customers who churned |
| Churn Rate (%) | Percentage of customers who churned |

**High-Risk Definition**

A customer is classified as **High Risk** if all of the following conditions are met:

- Month-to-month contract
- Monthly Charges greater than £70
- Tenure below 12 months

# Advanced Analysis

## tbl_MultiDimensionChurn

| Column | Description |
|----------|-------------|
| Contract | Customer contract type |
| Tenure Band | Customer lifecycle stage |
| Revenue Tier | Customer value category |
| Customers | Number of customers |
| Churned | Number of churned customers |
| Churn Rate (%) | Percentage of churned customers |

---

## tbl_EstimatedLTV

| Column | Description |
|----------|-------------|
| Contract | Customer contract type |
| Churn Status | Churned or retained |
| Avg Tenure (Months) | Average customer tenure |
| Avg Monthly Charge (£) | Average monthly subscription charge |
| Estimated LTV (£) | Estimated Lifetime Value calculated as: Avg Tenure × Avg Monthly Charge |

---

## tbl_CohortLagAnalysis

| Column | Description |
|----------|-------------|
| Cohort | Customer tenure cohort |
| Churn Rate (%) | Churn rate for the cohort |
| Previous Rate (%) | Previous cohort churn rate |
| Change (pp) | Percentage point change compared with previous cohort |

---

## tbl_PerfectStormChurn

| Column | Description |
|----------|-------------|
| Tenure Band | Customer tenure category |
| Customers | Number of customers |
| Churned | Number of customers who churned |
| Churn Rate (%) | Churn rate for customers matching the highest-risk combination |

**Perfect Storm Combination**

- Month-to-month Contract
- Fiber Optic Internet
- Electronic Check Payment Method

---

# Notes

- SQL is the project's computation layer.
- Excel serves as the presentation and dashboard layer.
- All dashboard metrics originate directly from validated SQL outputs.
- Monetary values are presented in **GBP (£)**.
- Churn is represented as a binary outcome (**Yes/No**) from the IBM Telco Customer Churn dataset.
